# Формат статичных стикеров Telegram

Проверено по официальной документации 2026-10-12.

## Требования Telegram

| Параметр | Требование |
| --- | --- |
| Формат для загрузки | PNG или WebP |
| Размер изображения | Одна сторона ровно 512 px, другая не больше 512 px |
| Размер файла | Не больше 512 KB по документации импорта |
| Прозрачность | Документация импорта требует прозрачный слой |
| Анимация | Для статичных стикеров WebP без анимации |
| Эмодзи | При импорте каждому стикеру назначается минимум один эмодзи |

Основная [страница Telegram](https://core.telegram.org/stickers#static-stickers-and-emoji) описывает PNG/WebP и размеры. Прозрачный фон, белую обводку и чёрную тень она рекомендует для читаемости. [Документация импорта](https://core.telegram.org/import-stickers#static-stickers) явно требует прозрачный слой и указывает лимит 512 KB; обводка и тень описаны как рекомендуемое оформление. Не считать их отдельной проверкой формата файла.

В [документации API](https://core.telegram.org/api/stickers#static-stickers) статичные стикеры описаны как WebP с MIME-типом `image/webp`. Это не отменяет возможность загрузки PNG.

## Фактические оригиналы

В `telegram/stickers/orig/` находятся 25 файлов WebP, каждый 320×320 px. Контейнеры содержат `VP8X`, `ALPH`, `VP8 `: изображение с потерями и отдельным альфа-каналом, без анимации. Размеры файлов: 20 060–35 418 байт. Параметры прочитаны из файлов, а не определены по расширению. Наличие альфа-канала проверено по контейнеру; это не попиксельная проверка прозрачности.

Формат и вес подходят, размеры не соответствуют требованиям загрузки: нет стороны 512 px. Причина уменьшенного разрешения неизвестна. Эти файлы сохраняются как исходные материалы, а не как готовые файлы для повторной загрузки.

Подробный перечень: [реестр стикеров](../telegram/stickers/registry.md). На момент инвентаризации PNG в рабочей папке отсутствовали.

## Правила проекта для новых стикеров

- Итоговый экспорт: статичный PNG или WebP, прозрачный фон, холст 512×512 px. Квадратный холст — наше соглашение; Telegram допускает прямоугольный.
- Держать файл в пределах 512 000 байт: это консервативный порог проекта для указанного Telegram лимита 512 KB.
- Сохранять читаемость персонажа и белую обводку по образцу оригиналов. Проверять края на светлом и тёмном фоне.
- Оригиналы в `orig/` не перезаписывать и не перекодировать. Производные оригиналов сохранять в `export/`. По указанию пользователя новые работы хранить в `new/<ID-название>/vNNN/`: `source.png`, итоговый `sticker.png` или `sticker.webp`, точный `prompt.md` вместе. Для выбора делать несколько вариантов, по умолчанию два. Сохранять отдельный промпт каждого варианта и ссылки на референсы.
- Для каждой новой работы добавлять запись в реестр: постоянный ID, эмодзи, описание, исходник, экспорт, размеры, вес, статус. Вариантам давать отдельные ID и ссылку на исходную запись.
- Перед статусом `ready` проверить формат, размеры, вес, прозрачность и внешний вид. Загрузка в Telegram и статус `published` требуют фактической публикации; локальная проверка её не подтверждает.

## Подготовка существующих файлов

Для будущей загрузки сделать отдельный экспорт с одной стороной 512 px. Увеличение 320→512 само по себе не добавит деталей: при наличии более качественного исходника использовать его. Пока экспортов нет, статус оригиналов — `needs_resize`.
