# Стикеры с рысью

Исходные стикеры, новые варианты, промпты генерации и готовые файлы для Telegram.

- [Правила проекта](lynx/agents.md)
- [Реестр стикеров](lynx/telegram/stickers/registry.md)
- [Требования и экспорт](lynx/docs/telegram-sticker-format.md)

## Структура

- `lynx/telegram/stickers/orig/` — неизменяемые оригиналы.
- `lynx/telegram/stickers/new/<ID-название>/vNNN/` — варианты новых стикеров.
- `source.png` — исходник генерации; `source-initial.png` — результат до правок, если они выполнялись.
- `prompt.md` — точные промпты, референсы и параметры.
- `sticker.png` и `sticker.webp` — экспорты 512×512 с прозрачностью.
- `preview-*.png` — проверочные превью на светлом и тёмном фоне.

Новые варианты сохраняются отдельно, предыдущие не перезаписываются. Готовность файлов и выбор пользователя отмечаются в реестре. Статус `ready` означает локальную проверку, а не публикацию в Telegram.
